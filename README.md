# Survival Island 3D 🌴

"Survival Island 3D" is a 3D mobile survival adventure game built using **Unity** and **C#**, designed specifically for Android mobile devices. 

---

## 🎮 Gameplay Features
- **Tropical Island Environment:** Explore beaches, forests, mountains, and rivers.
- **Third-Person Controls:** Smooth walking, running, jumping, and camera rotation with an on-screen mobile virtual joystick.
- **Resource Gathering:** Collect wood, stones, and fruits from the environment.
- **Crafting System:** Build campfires and shelters using gathered materials.
- **Inventory & UI:** Real-time resource tracking and interactive menus.
- **Offline Play:** Fully playable offline after installation.
